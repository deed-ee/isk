# ADR NNNN: Decision title

- Status: proposed / provisional / accepted / rejected

## Context and alternatives

Describe the smallest viable change, the previous ISK behavior, and relevant
alternatives.

For a significant language feature, address the [innovation gate](../architecture.md#language-innovation-gate),
including a tooling-only alternative and a rejection condition.

## Agent-efficiency hypothesis and acceptance criteria

State the task, comparison baseline, primary measure and threshold, and
supporting measures. Specify correctness, maintainability, determinism,
safety, native performance, and memory constraints. State the task context
and how missing measurements will be handled.

## Evidence and decision

Link raw results and reproducibility information. Record failures,
variability, and limits on generalization. State whether to keep, revise, or
reject the design. If evaluation is pending, keep the design provisional.
